K7 CREW V7.0 CONNECTED COMMUNITY — RELEASE CANDIDATE (НЕ PRODUCTION)

База: V6.4, проверена по Git blob SHA в GitHub. Файлы изменяют только перечисленные участки; CINEMA-видео, заставка, Telegram-сессия и текущие API управления сохранены.

Функции: фоновый polling (чат 3 с, публикации/события/статистика/состав/обращения 15 с), открываемые профили, редактирование своих данных, стаж с profiles.created_at, статистика из player_match_stats, закрытая загрузка фото JPEG, галереи до 6 фото, 16 фиксированных шаблонов по пяти публичным разделам, шаблоны внутренних ответов на обращения. Структурные события, состав и матчи сохраняют отдельные действующие формы.

Перед развёртыванием:
1. Сохранить резервную копию базы. Проверить наличие миграций 001–006. Не запускать повторно старые миграции.
2. В CI распаковать архив поверх точной базы V6.4, проверить SHA из BASELINE_SHA.json, выполнить npm install, npm run check:encoding, npm run check:assets, npm run test:local, node scripts/test-v7.cjs, npm run typecheck, npm run build. Не пушить автоматически, пока проверки не пройдены.
3. В тестовом Supabase применить 007 и 008 в этом порядке. Они добавляют поля и закрытое хранилище, не удаляя таблиц и записей. Для production сначала проверить резервную копию и staging; только затем применить миграции перед выкладкой кода. Действующая V6.4 совместима с добавленными полями. Не отменять миграции DROP TABLE/DROP COLUMN при откате приложения.
4. Проверить в Telegram iOS/Android: вход, 3-секундную заставку, отсутствие перезапуска баннеров, плавность прокрутки, редактирование своего профиля, запрет изменения чужого профиля/ролей, приватность имени/возраста, автоматическое появление новых публикаций и результатов, фото и галереи, редактирование старых публикаций, права владельца и IGL, отсутствие доступа участника к загрузке/админ-операциям. Проверить большие/повреждённые изображения. HEIC зависит от поддержки декодирования устройством.

Ограничения кандидата: новая гарнитура для произвольного текста не реализована, использованы существующие PNG BrandLabel и прежняя текстовая типографика. Новый визуальный вид шаблонов и профиля ещё не проверен на смартфоне. Роль ADMIN в текущей архитектуре legacy, без прав управления; действующие права OWNER/IGL не расширены. Supabase Realtime не подключён; используется защищённый API polling. Ответы в обращениях остаются внутренними заметками как раньше, не новым публичным каналом. Фото, загруженные и не прикреплённые к публикации, остаются в закрытом хранилище; нужна политика уборки сирот перед массовым использованием. Лимит загрузки 2 МБ после оптимизации; оригинал до 25 МБ. Тестов живой БД, полноценного typecheck/build и реальной плавности не было. Не устанавливать как окончательную production-версию до этих проверок.

Локально: синтаксис TS/CSS, 12 исходных assertions, 21 V7 assertion, UTF-8, 362 PNG. Установка npm offline недоступна из-за отсутствия пакетов в кэше.
